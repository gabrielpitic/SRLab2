# Sisteme de recomandare

## Lab 2 - My music store

### Dataset

- **Sursa:** [Spotify Tracks Dataset](https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset) (Kaggle)
- **Fisier folosit:** `spotify_tracks.csv` cu 1000 piese din acel data set
- **Domeniul ales:** Muzica, un "magazin" (fictiv) de piese muzicale -> `mymusicstore.ro`.

### Proprietati

| Proprietate | Tip | Descriere |
|---|---|---|
| `artists` | string | Artistul piesei |
| `album_name` | string | Numele albumului |
| `track_name` | string | Titlul piesei |
| `track_genre` | string | Genul muzical |
| `duration_ms` | int | Durata piesei, in ms |
